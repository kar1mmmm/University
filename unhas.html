Fakultas dan Program di UNHAS

Fakultas Ekonomi dan Bisnis (FEB)

Program studi di bidang ekonomi, manajemen, dan akuntansi.

Fakultas Hukum (FH)

Program studi di bidang hukum dan peraturan.

Fakultas Kedokteran

Program studi di bidang kedokteran dan ilmu kesehatan.

Fakultas Teknik (FT)

Program studi di bidang teknik dan teknologi.

Fakultas Pertanian (FP)

Program studi di bidang pertanian dan agribisnis.

Fakultas Ilmu Sosial dan Ilmu Politik

Program studi di bidang ilmu sosial, politik, dan hubungan internasional.

Fakultas Ilmu Budaya (FIB)

Program studi di bidang sastra, budaya, dan sejarah.

Fakultas Peternakan

Program studi di bidang peternakan dan ilmu hewan.

Fakultas Kesehatan Masyarakat

Program studi di bidang kesehatan masyarakat dan promosi kesehatan.

Fakultas Kedokteran Gigi (FKG)

Program studi di bidang kedokteran gigi dan kesehatan mulut.

Fakultas Kehutanan

Program studi di bidang kehutanan dan lingkungan hidup.

Fakultas Farmasi

Program studi di bidang farmasi dan ilmu obat.

Fakultas Matematika dan Ilmu Pengetahuan Alam (FMIPA)

Program studi di bidang matematika, fisika, kimia, dan biologi.

Fakultas Ilmu Kelautan dan Perikanan

Program studi di bidang perikanan, ilmu kelautan, dan teknologi hasil perikanan.

Fakultas Keperawatan

Program studi di bidang keperawatan dan ilmu kesehatan terkait.

Fakultas Kedokteran Hewan

Program studi di bidang kedokteran hewan dan kesehatan hewan.
