Tentang PTN INFO

Platform informasi terpadu untuk mengenal Perguruan Tinggi Negeri terbaik di Indonesia.

Apa itu PTN INFO?

PTN INFO adalah mini-situs direktori yang menghimpun profil 13 PTN unggulan Indonesia — mulai dari UI, UGM, ITB hingga UNAND. Situs ini dibangun sebagai Tugas 3 Desain Web (Progressive Mini-Site) dengan HTML semantik, CSS responsif, dan PWA agar tetap bisa diakses saat offline.

Data kampus diambil secara dinamis dari data.json melalui fetch() dan dirender ke DOM tanpa reload halaman.

Keunggulan Situs

Cepat & Ringan

Tanpa framework berat, hanya HTML/CSS/JS vanilla sehingga loading cepat.

Responsif

Layout Flexbox + Grid dengan media query, tetap terbaca di layar 400px.

Bisa Offline (PWA)

Service worker melakukan pre-cache, halaman utama tetap tampil saat jaringan mati.

Aksesibel

Semua gambar memiliki alt bermakna, setiap input memiliki label.

Statistik Singkat PTN

Contoh penerapan elemen tabel yang semantik dengan caption, thead, dan scope.
