Fakultas dan Program di UNS

Fakultas Keguruan dan Ilmu Pendidikan (FKIP)

Program studi di bidang pendidikan dan pengajaran.

Fakultas Hukum (FH)

Program studi di bidang hukum dan peraturan.

Fakultas Ekonomi dan Bisnis (FEB)

Program studi di bidang ekonomi, manajemen, dan akuntansi.

Fakultas Ilmu Sosial dan Politik (FISIP)

Program studi di bidang ilmu sosial, politik, dan hubungan internasional.

Fakultas Ilmu Budaya (FIB)

Program studi di bidang sastra, budaya, dan sejarah.

Fakultas Pertanian (FP)

Program studi di bidang pertanian dan agribisnis.

Fakultas Teknik (FT)

Program studi di bidang teknik dan teknologi.

Fakultas Kedokteran (FK)

Program studi di bidang kedokteran dan ilmu kesehatan.

Fakultas Matematika dan Ilmu Pengetahuan Alam (FMIPA)

Program studi di bidang ilmu pengetahuan dan matematika.

Fakultas Seni Rupa dan Desain (FSRD)

Program studi di bidang seni rupa, desain, dan kreatifitas.

Fakultas Ilmu Keolahragaan (FKOR)

Program studi di bidang ilmu keolahragaan dan kesehatan.

Fakultas Kedokteran Gigi (FKG)

Program studi di bidang kedokteran gigi dan kesehatan mulut.

Fakultas Psikologi (FPsi)

Program studi di bidang psikologi dan ilmu perilaku.

Fakultas Teknologi Informasi dan Sains Data (FTISD)

Program studi di bidang teknologi informasi dan sains data.

Sekolah Vokasi (SV)

Program studi vokasi di berbagai bidang keahlian.
